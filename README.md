#  Cyberpunk 2099: Skyline Overdrive

A high-velocity WebXR cyberpunk arcade flight game built using Three.js and JavaScript.

##  Live Demo

Play the game here:

https://roaring-baklava-4382cd.netlify.app/

##  Project Overview

Cyberpunk 2099: Skyline Overdrive is a futuristic arcade flight game where the player controls a hovercraft through a neon cyberpunk metropolis.

The project includes three game modes:

###  Cyber Circuit
Fly through 20 sequential holographic neon rings and beat the clock.

###  Data Core Hunt
Collect encrypted data cores throughout the city while avoiding security drones.

###  Free Cruise
Explore the futuristic cyberpunk city without timers, damage, or mission pressure.

##  Features

- 3D Cyberpunk Metropolis
- WebXR / VR Support
- Hovercraft Flight Controls
- Building Collision System
- Shield and Damage System
- Neon Forcefield Boundaries
- Dynamic Flying Traffic
- Security Drones
- 20 Ring Time Attack Circuit
- Data Core Collectibles
- Score and Combo System
- Nitro Boost
- 3D Waypoint Navigation
- Particle Effects
- Procedural Web Audio API Sound Effects
- Multiple Camera Views
- Pause, Game Over and Victory Screens
- Local Storage High Scores
- Responsive HUD and Controls

##  Controls

| Control | Action |
|---|---|
| W | Accelerate |
| S | Brake / Reverse |
| A / D | Steer |
| Arrow Keys | Steer |
| Space | Increase Altitude |
| Shift | Decrease Altitude |
| N | Nitro Boost |
| Mouse Drag | Steering |
| P / Pause Button | Pause Game |
